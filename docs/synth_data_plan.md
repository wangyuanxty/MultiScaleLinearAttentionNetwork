## 0. 为什么必须用合成，而不是找更多电池

```
库        训练电池数    EOL前50步的独立轨迹数
CALCE         3                  3
NASA          3                  2      ← B0007 从没穿过 EOL
MIT           8                  8      （全库 43，唯一有存量的库）
```

MIT 8 → 39 是唯一一次真·增加独立轨迹数的对照（4.9×），**但它 39 那一臂只有 1 个
seed，而且算力没对齐**（见 §5）。想在这条轴上有结论，要么把 MIT 补到多个 seed
（87 分钟/seed），要么自己造轨迹。造轨迹还能顺带控制"多样性"这个变量。

## 1. 三条已经走不通的路（记下来，别再走）

| 做法 | 结果 | 死因 |
|---|---|---|
| **i.i.d. 高斯噪声**加到容量序列 | TF 与 AR **全面变差** | 真电池残差 ACF@1 = 0.24–0.61，i.i.d. 是 0。同样的 σ 下逐 cycle 位移被放大 1.6×，实测 drop/cyc 2–4×。**窗口的局部斜率被砸烂**，模型学到的是"σ 这么大就不可预测"——正好是冻结的成因 |
| **相位随机化替代残差**（保留 ACF） | ACF 修好了，但仍测不了 | `trend + surrogate(resid)`——**trend 逐点不变**。27 条合成电池的 Q(n) 是同一条曲线，**独立轨迹数还是 3** |
| **NASA 加噪 3 → 30** | 30 更差 | **双重无效**：独立轨迹数 +0；而且两臂梯度步数 600 vs 6000，**算力没对齐**，混淆了 |

**共同的教训**：动残差改不了"有几条轨迹"；而"有几条轨迹"才是假设本身。

## 2. 生成器：动 trend

```
Q(n) = Q₀ − α·√n − β·max(0, n − n_k)^γ + ε_n
        │     │            │        │
        │     │            │        └ 膝部指数（γ > 1 给陡峭的拐点）
        │     │            └ 拐点位置 ← 决定"在第几个 cycle 开始陡"
        │     └ 拐点前的衰减速率
        └ 首圈容量
```

- `α·√n` —— SEI 生长的 √t 律，锂电衰减的标准形式
- `β·(n−n_k)^γ` —— 拐点（析锂）之后的加速相；`γ > 1` 时在 `n_k` 处值和斜率都连续，
  过渡平滑
- `ε_n` —— 残差，**复用 `synth_cells.py` 的相位随机化替代残差**（这一部分已经验证过：
  σ 与 ACF 都能对上真电池）

**参数怎么来 —— 不是拍脑袋：**

1. 对 3 条真训练电池**逐条最小二乘拟合** `(Q₀, α, β, n_k, γ)`，报出拟合值和残差
2. 看这 3 组值的**散布**，作为抽样范围的锚
3. 3 个点估散布太弱 —— 所以**抽样范围要比观测散布宽**，并且**把宽度报出来**
4. 抽样用 log-uniform（除 `n_k`、`γ` 用 uniform），保证不为负

> ⚠️ `Q₀` 和 `α` 在拟合里是强耦合的（首圈附近两者互相抵消）。要么固定 `Q₀` 为真电池
> 首圈实测值，要么用先验约束。**不处理的话抽出来的参数没有物理意义。**

## 3. 验收标准（硬指标，全过才开训）

**A. 每条合成电池都必须穿过 EOL。**
NASA 的 B0007 从没穿过 1.400 Ah，意味着它在"EOL 前 50 步"这个 regime 里**根本不存在**
——3 条训练电池实际只有 2 条。抽样时必须过滤。

**B. near-EOL drop/cyc 比值落在 [0.7, 1.4]。**
这是抓住 i.i.d. 那个 bug 的指标：EOL 前 50 步的 `mean|Δ|`，合成 ÷ 真电池。
i.i.d. 版是 2.0–4.0，替代残差版 1.6–2.9。

**C. (水平, 窗口 σ) 平面上的覆盖。**
把真电池和合成电池的每条 (level, window-σ) 轨迹画在一起。要求：
- 合成轨迹落在真电池占据的区域内（不跑到离谱的地方）
- **且延伸到真电池没有覆盖的区域** —— 否则就是没加新信息，跟残差版一个下场

**D. 参数散布表。**
报出 3 条真电池的拟合值，和 N 条合成的抽样值分布。**没有这张表就不算通过。**

**E. 对照臂自检。**
用 `s = 0`（零宽度抽样 = 原样复制 3 条真轨迹）跑一遍，它的 TF/AR 应该几乎等于
对照臂本身。**对不上说明管线里有别的东西在动。**

## 4. 实验设计

| | |
|---|---|
| 数据 | **CALCE**（AR 4/10 最差，论文主库；EOL 后还有 241 个 cycle，能跑满 EOL±50）|
| 测试电池 | `CS2_35` **整条不参与训练**（不用 SP 切分）|
| 归一化 | `lo`/`hi` **固定用 3 条真训练电池**——所有臂共用，避免"数据多了"和"刻度变了"混在一起 |
| 对照臂 | 3 条真训练电池 |
| 加料臂 | 3 真 + N 条合成（**N = 20**），每条 ~300–400 cycle |
| AR 协议 | EOL−50 起跑，跑到序列尾；**AE 永远有定义**（不穿越 = 取 `结束cycle − EOL` 作下界）|
| 指标 | **TF MAE / R²** ＋ **AR MSE / AE**（不看穿越率）|
| seed | 先 1 个跑通，再 3 个 |

**算力对齐（这次必须做）：**

`train_one` 每 epoch 走 `ceil(N/64)` 步。所以：

```
对照   3 真   × 100 epoch
加料 A 3+N    × EPOCHS_A epoch，  EPOCHS_A = 100 × N_ctrl / N_aug   ← 同步数
加料 B 3+N    × 100 epoch                                            ← 同 epoch（参考）
```

**A 赢对照 → 是数据量；只有 B 赢 → 是算力；都不赢 → 假设否掉。**

## 5. 已知的坑（每条都踩过）

1. **算力混淆** —— 固定 100 epoch 时，数据量翻 10 倍就是梯度步翻 10 倍。NASA 那次
   600 vs 6000 步，结论作废。
2. **AE 必须永远有定义** —— "从不穿越"不是缺失值，是"至少错了这么多"。报 `--` 等于
   把偏差藏起来，正是 AE 口径要避免的。
3. **不看穿越率** —— 它只有一位信息，而且会掩盖偏差。用 MSE + AE。
4. **单 seed 无意义** —— MIT 8 电池 10 个 seed 的 MSE 跨了 **500 倍**。任何 1-seed
   的比较都可能纯属偶然。
5. **不要覆盖任何已有脚本或 ckpt** —— 新脚本新路径。
6. **`lo`/`hi` 必须固定**，否则归一化跟着数据量一起变。
7. **合成电池绝不能进测试集**，`run_one` 要把训练 caps 和测试 caps 分开传。

## 6. 执行步骤与成本

| # | 步骤 | 产出 | 估计 |
|---|---|---|---|
| 1 | 拟合 3 条真电池 → `(Q₀,α,β,n_k,γ)` | 拟合表 + 残差图 | 分钟级 |
| 2 | 抽样 N 条 + **§3 全部验收** | 验收报告；**不通过就停** | 分钟级 |
| 3 | 三臂 × seed1 计时 | 单臂实际耗时 | —— |
| 4 | 三臂 × 3 seed | TF + AR 表 | 见下 |
| 5 | （可选）多样性扫描 `s = 0.5 / 1 / 2` | AR vs 多样性曲线 | 翻倍 |

粗估：对照约 20 分钟/seed；加料 A（同步数）与之相当；加料 B（100 epoch）约 2.5 小时。
**3 seed 全跑约 9 小时，过夜。**

先做 1、2 再谈 3——**验收不过就不训。**

## 7. 判定标准

| 结果 | 结论 |
|---|---|
| 加料 A（同步数）打赢对照 | **数据量成立**，假设得证，叙事要重写 |
| 只有加料 B（100 epoch）赢 | 是**算力**，与数据量无关 |
| A、B 都不赢 | 假设在 3→23 条轨迹区间内**被干净地否掉**（这次算力对齐、残差匹配、单变量） |

无论哪个结果，**TF 与 AR 的分离**本身就是可写的：MIT 上 39 电池的 TF 打穿 8 电池
全部 10 个 seed，AR 却完全没跟上——**拟合最好的模型 roll-out 并不是最好的**。
